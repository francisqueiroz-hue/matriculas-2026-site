# Ritmo — planejador visual pessoal

PWA sem dependências, inspirado na ideia de planejadores visuais para TDAH. Dados só no aparelho (localStorage).

- **Hoje:** linha do tempo com blocos coloridos, emoji, passos e conclusão.
- **Timer visual:** disco que diminui, pausa, ±5 min, alerta sonoro e notificação.
- **Tarefas:** lista rápida, divisão em passos, agendar no dia.
- **Foco:** pomodoro configurável (foco/pausa).
- **Rotinas:** modelos aplicáveis a qualquer dia. **Backup:** exportar/importar JSON.

Rodar: `cd ritmo && python3 -m http.server 8000` e abrir `http://localhost:8000`.
Para instalar no celular, hospede a pasta em HTTPS (ex.: Vercel/GitHub Pages) e use "Adicionar à tela inicial".
